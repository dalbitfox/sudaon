## 실제 수행한 검증

- 웹 프로덕션 빌드 성공.
- 통합 테스트 7개 통과: 권한·입장·실시간 전달·중복 방지·삭제·내보내기·종료·정원·이력·Excel·저장 복구·키워드·초기 설정 상태.
- npm 의존성 감사에서 0개 취약점 확인. 실행 시점의 레지스트리 결과이며 미래까지 보장하지 않는다.
- Electron의 내장 Node 환경에서 `node:sqlite` 사용 가능 확인.
- 브라우저에서 발표자와 청중 화면의 실제 메시지 왕복 및 집계 반영 확인.
- 첫 로컬 부하 검사: 청중 200명 + 운영자 1개 연결, 원본 메시지 60개, 전달 12,000회, 유실·중복 0, p95 874ms.
- 고정 전송률 90초 추가 검사: 원본 200개(정상 180 + 순간 유입 20), 전달 40,000회, 유실·중복 0. p95 1,114ms로 1초 목표 미달. 로컬 갱신 간격을 500ms에서 200ms로 보완했다.

- 보완 후 동일한 90초 검사 통과: 청중 200개 + 발표자 1개 연결, 정상 180개·추가 20개 메시지, 수신 40,000회, 유실·중복 0, p95 **227ms**. [측정 결과](validation/local-200-clients.json). 이 결과는 로컬 Node/SQLite 환경만을 검증한다.
- 375×812 모바일 및 812×375 가로 화면에서 가로 넘침 없이 입력창이 화면 안에 표시되는 것을 확인했다.
